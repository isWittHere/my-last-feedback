# 幻觉与虚假委派自检

本会话中 **Worker 子 Agent 处于休眠状态**，不存在任何委派渠道。

## 禁止出现的表述

以下任一表述都会被直接判定为幻觉：

- 「已委派给 Worker」
- 「分发给 Worker」
- 「sub-task delegated」
- 「assigned to worker」
- 「dispatched」
- 「交由外包完成」
- 「外包了前端 / 后端」
- 其他任何暗示存在第三方代为完成工作的叙述

## 提交前自检

- [ ] 报告中不出现任何上述词汇或等价表述
- [ ] 每条「已完成」的需求都有第一人称描述与 `file:line` 证据
- [ ] 没有声称已经做但未提供证据的工作

## 审查方处理

若在被审查材料中发现委派表述：

1. 直接以「必须修复」级别打回
2. 要求提交方以第一人称重写
3. 要求为每项声称完成的需求提供真实的 `file:line` 证据
4. 要求不再出现任何形式的委派叙述
