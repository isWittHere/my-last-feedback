### 2.2 `mlra-server/server.mjs`（MCP 工具注册）

主 agent 会通过 MCP 看到工具列表。**需要让主 agent 完全看不到 worker 类工具**。

| 工具 | 当前暴露对象 | 改造动作 |
|------|---------|---------|
| `register_LRA` | 所有 | 保留 |
| `get_task_context` | 主 agent | 保留，但描述中删除 "workers cannot" 这种反向引用 |
| `submit` | 所有 | 保留 |
| `router_vote` | 主 agent | 保留 |
| `order`（L353-) | 实施专家 | **条件注册**：`if (WORKER_ENABLED) mcpServer.tool("order", ...)` — 关闭时不挂载此工具，主 agent 的工具列表中不存在 |
| `check_orders` | 实施专家 | **条件注册**，同上 |
| `await_order`（若存在） | 实施专家 | **条件注册**，同上 |
| `submit_feedback`（Worker 用） | Worker | **条件注册**，同上 |

**关键原则**：用"不注册工具"替代"注册后运行时拒绝"。前者主 agent 根本看不到，不会产生"我试着调用但被拒"的困惑；后者会产生幻觉调用。
